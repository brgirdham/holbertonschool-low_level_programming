This README is for the simple calculator project.

Compile Command:
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

Run Instructions:
To run calculator use ./calculator

Supported Operations:
Addition, Subtraction, Multiplication and Division

Numeric Beheaviour:
I've coded it so that all results come back with the number to 2(two) decimal places

Known Limitations:
That the results only come back to 2(two) decimal places, for more precise measurments I would need to changed the floats from %.2f to %.6f to account for that. As it is a simple calculator, cannot do scientific calculations and is limited to just the basic functions that I've noted down.
